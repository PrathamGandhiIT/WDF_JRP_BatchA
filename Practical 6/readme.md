# Practical 6: Rendering External JSON Data using Fetch API, Search and Filter

## Objective
Display events list from external `events.json` using JavaScript Fetch API. Implement dynamic table rendering, real-time search, category filter, sorting, and pagination logic with local caching.

## Files
- `index.html`: Responsive layout with search, category filter dropdown, sort select, dynamic table, and pagination controls.
- `style.css`: Clean, modern UI styling with responsive tables and status badges.
- `script.js`: Fetch API request, JSON parsing, array filter/sort/slice logic, and DOM manipulation.
- `events.json`: JSON dataset containing 15 structured event records.
